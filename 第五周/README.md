## 这一步做什么
把题目直接交给大模型一次（不加资料、不调工具），看它自己一次能答成什么样。

## 要求
一次调用给一个答案：不查资料、不调工具、不重试。
记录用的模型和提示词；给的示例只能从开发那份数据里挑。
报告里写清它错在哪、错在哪些题（跟传统方法比）。
## 要交的东西
提示词（不给示例、给示例两版）
模型与参数记录
基线报告（按模板四节写：目标与完成情况、核心材料、问题分析与改进、分工安排）
验收标准
无工具和自动检索；同测试集真实运行，完整保留成功与失败，不以效果高低判定完成。

027 组的实验报告、两版提示词、模型配置和逐题记录见 [M5 实验材料](M5_平台提交_027/README.md)。
