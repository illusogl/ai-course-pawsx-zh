# M3 平台提交版本说明

本目录是组员在课程平台已完成提交的 M3 传统方法实现，由 EasonZG 按组长赵国安排于 2026-11-23 上传到本仓库，供组内复核与后续 M4 使用。

## 来源与状态

- 来源：本地课程工作区 `第三周/M3提交包/`，2026-11-16 完成。
- 平台状态：2026-11-23 平台截图显示 M3 传统方法实现为“已完成”。
- 平台 test 400 的具体分数未在本地记录，本目录不虚构该成绩。
- 本目录与 `第三周/M3_提交包/` 的旧 CPU TF-IDF 路线是两套不同实现；本目录是字级特征 + 单隐层 tanh MLP 的平台提交版本。

## 方法

- 特征：23 项字级句对特征，包括字符 1/2/3-gram 的 Jaccard 与包含度、长度比、LCS 比率、数字与否定差异、连续匹配片段、数字/方位次序、拉丁拼写不对称及若干交互项。
- 模型：输入 23 维、隐层 16 个 tanh 单元的单隐层网络，Adam 优化，L2=1e-4，batch=256，seed=0。
- 选模：训练集 44,898 条；验证集去掉 dev100 同 ID 后剩 1,846 条用于调参；选中学习率 0.01、训练 30 轮、判定阈值 -0.40。
- 推理：`oj/run.py` 只依赖 Python 标准库和随包 `models/trad.json`，不调用大模型或远端 API。

## 复现

本目录不包含课程数据，避免重复入库。复现时把课程数据包的 `data/` 放到本目录根下，然后执行：

```bash
python -m pip install -r requirements.txt
python oj/selfcheck.py --method trad
python oj/evaluate.py
python oj/run.py --method trad --split test --input data/test_inputs.jsonl --out runs/trad/results.test.jsonl --seed 0
```

训练可用 `python oj/train.py --seed 0`。`requirements.txt` 为本次上传补充，原提交包未附该文件。
